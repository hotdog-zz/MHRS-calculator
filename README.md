# 曙光配装工房

为《怪物猎人崛起：曙光》最终内容版寻找配装。选择武器、设置目标技能，工房会搜索五件防具、护石、防具炼化和普通珠子的插法；也可以导入自己的装备箱，只使用已经拥有的装备配装。

本地版内置数据和求解引擎，无需登录，计算时无需联网。只模拟配装无需安装游戏 Mod；将方案带入游戏、导出装备箱或清理装备时，需要使用配装管理器 Lua 和相应前置。

## 打开本地版

1. 解压整个压缩包。
2. 用支持 WebAssembly 和 Web Worker 的现代浏览器打开 `SunbreakForge.html`。
3. 选择武器、添加目标技能，点击“开始配装”。

如果浏览器限制直接打开本地文件，可在安装 Python 3 后使用本地启动脚本：

| 系统 | 启动方法 |
| --- | --- |
| Windows | 双击 `start-windows.bat` |
| macOS | 运行 `start-macos.command`，或执行 `python3 start_local.py` |
| Linux | 执行 `sh start-linux.sh` 或 `python3 start_local.py` |

启动后会自动打开浏览器，默认地址为 `http://127.0.0.1:8787/`；端口被占用时会选择其他端口。服务只监听本机。运行期间保持启动窗口打开，按 `Ctrl+C` 停止。

`dist/index.html` 用于本地服务器访问。直接双击时请使用 `SunbreakForge.html`。

## 设置技能并搜索

1. 在“01 选择武器”中选择武器种类和具体武器，可按名称搜索。百龙珠可以选择或空置，只显示当前百龙孔能容纳的珠子。
2. 在“02 目标技能”中添加技能并设置等级。点击“排序”可整理目标列表；结果技能按显示等级降序、同等级按技能 ID 升序排列。
3. 在“03 固定装备与炼化上限”中按需指定防具、炼化、护石和各部位的新增正面词条上限。
4. 在“04 搜索条件”中设置性别、防具范围、炼化选项、搜索时限和排序目标。
5. 点击“开始配装”。结果会列出装备、护石、炼化、全部技能和逐孔插珠位置；搜索过程中可以停止。

目标技能是最低要求，结果可以多出技能或溢出等级。允许删除原生技能时，没有要求的技能也可以删除并返还炼化 cost。

搜索有两种方式：

- **达到方案数量后结束**：找到指定数量的方案后停止。
- **按时限优化排序指标**：在时限内继续搜索，优先优化所选的基础防御、炼化新增技能等级或新增技能 cost。

基础防御越高越优时选择降序，新增技能 cost 越低越优时选择升序。新增技能 cost 只合计防具炼化增加技能的费用，不包含孔位、其他属性或删除技能返还的费用。

搜索使用两个独立计算 Worker，可能占用较多 CPU 和内存；停止搜索会结束两路计算。未找到方案不代表一定无解，可以延长时限或放宽条件。结果不保证全局最优。

### 固定防具、炼化和护石

- **指定装备**：选择某一部位的防具。默认只固定防具，炼化由工房搜索；其他未固定部位也由工房搜索。
- **同时固定炼化**：勾选后填写该件防具的炼化词条。空列表表示无炼化。固定后不会额外增加或替换词条，普通珠子由工房安排。
- **指定护石**：搜索并选择第一、第二技能，填写等级和孔位；第二技能可以留空。保存时会检查技能和联合孔位是否合法。
- **从当前 Mod 模板固定装备**：导入模板后，可分别选择固定的防具部位、对应炼化和护石。
- **固定这套装备**：在结果卡片上固定整套防具、炼化和护石，便于调整目标后继续搜索。可以逐部位解除装备固定，或只解除炼化固定。

固定配置需要符合当前性别、防具范围、炼化开关和词条限制；冲突时按提示调整条件或解除固定。

各部位的“最多新增正面词条”可设为0～7，默认7。技能每增加一级计1条；孔位增长＋1、＋2或＋3均计1条。技能删除、防御和耐性变化不计入这个新增上限，但仍占用炼化记录并参与预算计算。

## 使用自己的装备箱配装

### 安装 Lua 并导出库存

1. 按[配装管理器 Mod 原帖](https://www.caimogu.cc/post/2330778.html)安装前置。
2. 关闭游戏，备份存档和原脚本，将本地包中的 `dist/EquipmentLoadoutsManager.lua` 放到 `MonsterHunterRise/reframework/autorun/EquipmentLoadoutsManager.lua`。网页“我的装备箱”也提供脚本下载。同一功能只保留一个自动运行脚本，避免重复加载。
3. 进入角色据点，打开 REFramework 菜单中的“配装管理器 · 曙光工房”。在“库存与网页”页点击“导出完整装备箱（只读）”。
4. 导出文件位于 `MonsterHunterRise/reframework/data/EquipmentLoadouts/Inventory/`，文件名为 `inventory_SBFI1-….json`。将文件拖入网页“我的装备箱”。

导出操作读取装备、实际炼化、护石、珠子和游戏装备组合引用，不修改装备。

库存页按武器、防具、护石、珠子分类，可按名称或技能搜索。排序项目随类别变化，支持升序和降序；武器、防具支持稀有度排序。同型号装备按具体箱位分别展示，重复珠子合并为“×数量”。无法用于计算的条目会保留显示并说明原因。

### 计算已有装备方案

点击“用已有装备配装”，或勾选“仅使用已拥有的装备”，在“01 选择武器”中选定库存里的具体武器实例，然后设置目标技能并搜索。

此模式使用库存中的防具及实际炼化、护石和数量内的普通珠子，不生成新的炼化。“03”的固定装备和指定护石作为库存筛选条件；炼化开关、防御兜底和新增词条上限不用于改写已有装备。结果上的“固定这套装备”会固定具体箱位实例。

武器普通孔按原生孔位计算，实际强化和解锁状态保留。百龙珠沿用所选武器导出时的插法；需要更换时，在游戏中修改后重新导出库存。

珠子可用量以快照记录为准，不额外累加所有已镶嵌珠子，因此可能少于游戏内可调配的总量。

### 将已有装备方案带回游戏

1. 导入与目标武器同类型的 Mod 模板，用于保留替换技、朱／苍之书和花链。库存中须存在模板使用的花链；操虫棍还需先在游戏中为武器配好猎虫，再导出库存。
2. 在结果卡片点击“Mod 导出”，填写名称和游戏装备组合栏位（1～224）。
3. 将下载的 `owned_栏位_时间戳.json` 放入 `MonsterHunterRise/reframework/data/EquipmentLoadouts/OwnedPlans/对应武器类型/`，保留 `owned_` 前缀。
4. 在 Lua 的“配装列表”中刷新并加载。已有内容的组合栏位会被替换，加载时按提示确认。

已有模式会核对实时箱位、装备状态和珠子数量。校验通过后，将已有装备绑定到指定组合，并写入名称、替换技与插珠备份；不会创建、强化或重新炼化装备，也不会增加珠子数量或自动穿上该套配装。

整理或移动装备、改变炼化、强化、百龙珠、猎虫配对，或更换存档后，请重新导出库存并计算。导入提示库存不匹配时，请先更新快照。

## 使用普通配装方案导入游戏

普通模式可以搜索未持有的防具、护石和炼化。将这类方案带入游戏时，Lua 会按普通导入流程处理装备；请先备份存档，并查看“保留装备”等加载设置。

1. 在游戏中用配装管理器保存一套与目标武器**同类型**的组合，作为模板。模板通常位于 `MonsterHunterRise/reframework/data/EquipmentLoadouts/对应武器类型/`，例如弓为 `Bow`、太刀为 `LongSword`、双刀为 `DualBlades`。
2. 在网页点击“Mod 导入”，粘贴模板 JSON，或拖入／选择 JSON 文件，选择导入方式。
3. 计算出方案后，在结果上点击“Mod 导出”，填写显示名称和游戏装备组合栏位，再保存 JSON。
4. 将文件放到下载提示的对应武器类型目录，在 Lua 的“配装列表”中刷新并加载。

| 模板导入方式 | 作用 |
| --- | --- |
| 模板导入 | 保存模板、同步武器，保留当前目标技能和搜索选项 |
| 全导入 | 保存模板、同步武器，并将模板配装技能设为目标技能，保留搜索选项 |

导入模板不会改动已算出的结果；要使用同步后的武器配装，请重新搜索。导出武器以所选结果为准。

导出名称用于 Mod 列表和游戏内组合名称。文件名使用 `栏位_时间戳.json`，决定写入的游戏装备组合栏位；该栏位不是装备箱箱位。普通模式加载可能创建装备，并根据“保留装备”等设置处理目标组合关联的原装备。请核对目标栏位，避免覆盖需要保留的组合。

### 模板保留内容

模板用于保留替换技、花链、猎虫关联、装备锁定标记，以及武器炼化和解锁状态。普通模式导出的防具、护石和普通珠子按计算结果生成。

- 百龙珠优先使用结果中保存的选择，包括明确空置；结果未指定时使用模板配置。
- 模板武器炼化须适用于结果武器，百龙孔也须容纳所选珠子；不适用时会提示更换模板或武器。
- 同一件防具保留模板的铠玉强化点数，换成其他防具时归零。Lua 的防具强化设置也会影响游戏加载结果。
- 旧式百龙武器模型、百龙强化及历史记录未完整保留，相关字段会重置。
- 弩枪改装采用模板装备记录中的值。

Lua 菜单包括“库存与网页”“配装列表”“保存组合”“设置与工具”“清理未引用”。其中“保存组合”可导出单套或全部游戏组合；“设置与工具”用于普通方案的装备保留、武器词条解锁和防具强化设置。加载设置会影响游戏中的最终状态，不会改写已经下载的 JSON。

## 分享条件和完整方案

| 功能 | 用途 |
| --- | --- |
| 复制条件／导入条件 | 分享武器、目标技能、固定装备和搜索选项，用于重新搜索 |
| 导出 JSON／导入方案 | 保存或恢复具体装备、炼化、护石、技能和插珠结果 |
| 截图分享／导入方案 | 生成带二维码的配装图片，接收者可从图片或方案码恢复配装 |
| Mod 导入／Mod 导出 | 与游戏配装管理器交换模板和方案 |

网页条件和完整方案 JSON 不能直接作为游戏 Mod 文件加载。

条件和 Mod 模板可粘贴完整 JSON，也支持拖拽或选择文件；单个文件上限2MB。读取文件后点击对应按钮应用。

“截图分享”会生成包含武器、五件防具、护石、炼化、普通珠子和完整技能列表的图片，右下角二维码携带方案数据，无需账号或服务器记录。接收者点击“导入方案”，拖入／选择图片、粘贴剪贴板图片，或粘贴扫码得到的方案码；也可导入完整方案 JSON。图片和完整方案 JSON 上限20MB，转发时建议发送原图。

导入方案会校验并显示具体结果，同时固定方案，便于继续调整；需要重新搜索时可解除相应固定。二维码是数据文本，通用扫码工具不一定直接打开网页。

已有装备方案也可以截图分享，图片中保存为不依赖分享者库存的预设。接收者无需导入原库存即可查看并通过普通 Mod 导出使用；模板、替换技和武器强化配置由接收者自行提供。已有模式的完整方案 JSON 保留库存关联，在另一设备恢复时需导入对应库存快照。

## 清理未引用装备

**建议非必要不使用此功能。** 删除可能影响游戏存档，使用前请在游戏外备份完整存档。

清理入口位于 Lua 的“清理未引用”页，删除对象为武器、防具和护石。**所有范围都排除当前穿戴和被任何游戏装备组合引用的装备**；猎虫、花链和珠子本身不作为删除目标。

1. 在游戏外备份完整存档，回到据点并关闭其他装备编辑、出售、炼金或强化菜单。
2. 选择“批量范围”，点击“扫描 / 刷新未引用装备”。更改范围后重新扫描。
3. 逐件勾选，或按类别、名称、箱位筛选后点击“全选当前筛选（含所有页）”。切换筛选保留已选项，以“已选”总数为准；“取消全部选择”可清空。
4. 点击“删除已选装备…”，核对类别、锁定和镶珠件数，点击“确认删除 N 件”执行，或点击“取消”返回。

| 批量范围 | 锁定装备 | 镶珠装备 |
| --- | --- | --- |
| 未锁定且未镶珠（默认） | 排除 | 排除 |
| 未锁定 | 排除 | 可包含 |
| 未镶珠 | 可包含 | 排除 |
| 全部 | 可包含 | 可包含 |

以下装备固定排除，所有批量范围和全选均不能删除：黑带、黑带S、公会十字系列的全部五个部位；传承太刀及升级后的继承宝刀一系；祝福羽饰；家传、老练、新手护石。保护按游戏装备 ID 判断，与锁定状态、技能和镶珠情况无关。

普通珠和百龙珠都计入镶珠筛选。锁定和镶珠装备交由游戏出售接口处理，脚本不主动解锁、拆珠或添加珠子。**镶嵌珠子的实际返还效果尚未确认；需要保留珠子时，选择“未镶珠”范围或先在游戏中拆珠。**

扫描只读。删除前会自动保存库存备份，每件删除前后都会复核装备状态、穿戴和组合引用；不兼容或检测到异常时停止。自动生成的库存 JSON 不是完整游戏存档，也没有一键恢复保证；部分项目可能已经删除，请结合游戏状态和记录核对。

记录位于 `MonsterHunterRise/reframework/data/EquipmentLoadouts/Cleanup/`：`scan_….json` 为扫描报告，`backup_….json` 为删除前库存备份，`result_….json` 为执行结果。批量执行时保持在据点，不要同时整理装备或切换组合。清理完成后重新导出库存，更新网页快照。

## 配装规则与限制

- 数据面向《曙光》最终内容版。武器普通孔按原生孔位计算；百龙珠、武器炼化和花链不参与目标技能求解。
- 普通模式下，每件防具最多七条内部炼化记录，cost 总和不超过该件预算。这里的记录不是装饰品孔。
- 原生技能种类＋新增技能种类不超过五种，删除技能不释放原生种类名额。
- 同件防具不能既增加又删除同一技能，删除不得超过原生等级。
- 孔位增长遵守孔位升级规则；技能不能超出对应上限。
- 存在防御炼化记录时，防御增减合计不能为0；完全没有防御记录时允许。
- 检查炼化最终状态，不验证随机生成顺序或种子可达性。已有模式直接使用库存中的实际炼化和护石，不按普通搜索规则重新生成。
- 风雷合一的额外加成在 Mod 全导入时计入目标，求解按基础技能搜索，因此可能保守。
- 基础防御显示和排序不包含铠玉强化、武器炼化等效果，不等于游戏最终面板防御；工房不计算伤害。

### 防御兜底

“执行防御兜底”默认关闭。开启后，可炼化防具最多组合六条自由记录，再按剩余预算补一条防御词条。预算为0时留空；大于0时，选择所属池中预算内 cost 最大的专用兜底或普通加防御词条，相同 cost 优先专用兜底。只补一条，不反复消耗预算。

兜底占用炼化记录并参与预算、防御及合法性检查，不计入新增正面词条上限。专用兜底最多出现一次；固定炼化也需符合补偿规则。词条展示和 Mod 导出按词条 ID 升序排列，兜底预算摘要按实际计算结果显示。

## 数据保存与常见问题

条件、Mod 模板和库存保存在当前浏览器，不会自动同步到其他浏览器或设备。清除网页数据不会删除游戏装备，但会清除本机保存的网页记录；重要条件、模板和方案请另存文件。

- **找不到方案**：延长时限，检查性别、防具范围、固定装备和技能等级是否冲突；必要时降低要求。
- **已有模式提示库存不匹配**：重新导出游戏装备箱，导入快照后重新选择武器实例并计算。
- **分享图片识别失败**：使用原图，或裁出完整二维码并保留四周白边；也可以发送方案码或完整方案 JSON。
- **Mod 提示模板不适用**：使用同武器类型模板，并检查武器强化和百龙孔条件。
- **清理扫描不可用**：查看扫描报告；无法完整确认穿戴、组合结构或游戏接口时，删除不会执行。
