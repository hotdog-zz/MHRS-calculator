# 曙光配装工房

为《怪物猎人崛起：曙光》最终内容版寻找配装。选定武器和目标技能，工房会计算防具、护石、防具炼化及珠子插法；也可以只用自己装备箱里的装备配装。

**当前版本：0.7.1。** 本地版无需登录、无需联网计算。只使用配装和模拟功能不需要安装游戏 Mod。

## 开始使用

1. 下载 `MHRScalculator-071.zip`，解压整个压缩包。
2. 用现代浏览器打开 `MHRScalculator/SunbreakForge.html`。
3. 选择武器，添加想要的技能和等级，点击“开始配装”。

如果浏览器无法直接打开本地版，请安装 Python 3，再使用对应启动方式：

| 系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start-windows.bat` |
| macOS | 运行 `start-macos.command`，或执行 `python3 start_local.py` |
| Linux | 执行 `sh start-linux.sh` 或 `python3 start_local.py` |

启动后按窗口提示打开本机地址，使用期间保持窗口打开，结束时按 `Ctrl+C`。

## 配装工房

按页面的01～04依次设置：

1. **选择武器**：按名称搜索具体武器，也可选择百龙珠。
2. **目标技能**：添加技能并设置等级；目标是最低要求，结果允许更多技能或更高等级。
3. **固定装备与炼化上限**：可固定任意防具或护石。防具可以只固定装备，让工房搜索炼化；也可以勾选“同时固定炼化”，填写自己的词条。每件的“最多新增正面词条”限制炼化增加技能和扩孔的数量，技能每加1级算1条，扩孔＋1／＋2／＋3都各算1条。
4. **搜索条件**：选择性别、防具范围、是否炼化及搜索方式。“执行防御兜底”会在计算中加入游戏的防御收尾约束，详细规则见[配装规则](docs/rules.md)。

| 搜索方式 | 适合什么情况 |
| --- | --- |
| 达到方案数量后结束 | 想尽快得到几套可用方案 |
| 按时限优化排序指标 | 愿意多等一会，寻找防御更高、炼化技能费用更低或空余孔位更多的方案 |

结果会显示完整装备、护石、炼化、技能和逐孔插珠。技能等级数字变红，表示比本次目标多出的等级。可以点击“固定这套装备”，再调整技能继续搜索。

“空余孔位”按**空着的孔等级之和**计算：一个4级孔加两个1级孔算6；孔里插了珠子就不再计入。基础防御、满强化防御和耐性不包含技能、道具、猫饭等额外效果，可能与游戏最终面板不同。

未找到方案不一定代表无解，可延长时限或放宽固定条件。计算期间可能占用较多资源，可随时停止。

## 装备箱导入与已有装备配装

装备箱使用页面顶部的 **“我的装备箱”** 导入入口。这里需要游戏导出的**完整库存 JSON**，与单套配装的“Mod 导入”“导入方案”是不同功能。

### 1. 在游戏中导出装备箱

首次使用请先按下方[脚本安装步骤](#1-安装游戏端脚本)安装库存扩展 Lua；本地包中的脚本为 `dist/EquipmentLoadoutsManager.lua`。

1. 进入游戏角色据点，打开 REFramework 菜单中的 **“配装管理器 · 曙光工房”**。
2. 进入 **“库存与网页”** 页，点击 **“导出完整装备箱（只读）”**。
3. 看到导出成功后，到游戏安装目录打开：

```text
MonsterHunterRise/reframework/data/EquipmentLoadouts/Inventory/
```

找到刚生成的 `inventory_SBFI1-….json` 文件；有多份时，选择本次导出的最新文件。它记录武器、防具及实际炼化、护石、珠子数量和装备组合引用。导出只读取装备箱，不会修改游戏装备。

### 2. 把文件导入网页

1. 打开工房，点击页面顶部的 **“我的装备箱”**，切换到装备箱页面。
2. 找到 **“导入游戏库存”** 区域，将 `inventory_SBFI1-….json` 拖到 **“把装备箱 JSON 拖到这里”** 的框内；也可以点击这个框，在文件选择窗口中打开该 JSON。每次导入一份文件，最大32MB。
3. 选择后会自动读取，无需再点应用按钮。成功时页面显示 **“已载入本机库存”**，并出现导入件数、库存时间和装备列表。
4. 可按武器、防具、护石、珠子分类查看，使用名称或技能搜索，并切换排序。相同型号的装备按具体箱位分别显示，珠子合并显示数量。

如果出现错误，请按页面提示检查文件是否为完整库存导出，而不是单套 Mod 配装或网页搜索条件。

### 3. 启用已有装备配装

**导入库存后，还需要启用已有模式：**

1. 点击装备箱页面右上角 **“用已有装备配装”**，工房会返回配装页并启用已有模式；也可以回到“配装工房”，手动开启04中的 **“仅使用已拥有的装备”**。
2. 在01选择要使用的武器。如果拥有多把同型号武器，在 **“库存实例”** 中选择具体箱位。
3. 在02设置目标技能，按需在03固定防具或护石，再点击 **“开始配装”**。

已有模式只使用快照中的防具、实际炼化、护石和数量内的珠子，不生成新炼化。要把结果带回游戏，请按下方 Mod 导出步骤，将 `owned_` 开头的方案放入 `OwnedPlans/对应武器类型/`。

### 装备变动后怎样更新

库存是导出时的快照，不会实时跟随游戏变化。整理箱位、改变强化或炼化、百龙珠、猎虫配对，或更换存档后，请在游戏中重新导出，再到“我的装备箱”导入最新文件并重新计算。

库存保存在当前浏览器；换设备或浏览器时，需要重新导入文件。“清除本机记录”只清除网页库存，不会删除游戏里的装备。

## 把方案导入游戏

### 1. 安装游戏端脚本

工房的计算功能不依赖 Mod；要把配装写入游戏，需要配装管理器及其前置。请先阅读[Mod 原帖](https://www.caimogu.cc/post/2330778.html)，按原帖要求安装 REFramework 等前置。

关闭游戏并备份完整存档、原有脚本，再把本地包中的 `dist/EquipmentLoadoutsManager.lua` 复制到：

```text
MonsterHunterRise/reframework/autorun/EquipmentLoadoutsManager.lua
```

同一功能只保留一个自动运行脚本，避免新旧脚本重复加载。进入角色据点后，打开 REFramework 菜单，找到“配装管理器 · 曙光工房”。

| Lua 页面 | 用途 |
| --- | --- |
| 库存与网页 | 导出装备箱，供工房使用已有装备配装 |
| 配装列表 | 刷新文件并加载网页导出的 Mod 方案 |
| 保存组合 | 保存游戏中的单套或全部装备组合，取得模板 |
| 设置与工具 | 调整普通导入的装备保留、武器词条解锁和防具强化设置 |
| 清理未引用 | 可选的装备清理；非必要不建议使用 |

### 2. 从游戏取得模板

先在游戏中登记一套与目标武器**同类型**的装备组合，再通过 Lua 的“保存组合”页导出。模板保存了替换技、朱／苍之书、花链等网页不负责选择的配置，建议使用自己日常使用的组合。

导出的普通配装文件位于游戏的：

```text
MonsterHunterRise/reframework/data/EquipmentLoadouts/对应武器类型/
```

例如，弓对应 `Bow/`，太刀对应 `LongSword/`，双刀对应 `DualBlades/`。到这个目录找到刚导出的 JSON 文件。

### 3. 导入网页并计算

点击网页“Mod 导入”，拖入、选择文件或粘贴完整 JSON，再选择导入方式：

| 导入方式 | 目标技能 | 武器与模板 |
| --- | --- | --- |
| 模板导入 | 保留网页当前目标 | 同步模板中的武器，保存模板配置 |
| 全导入 | 用模板的技能替换网页目标 | 同步模板中的武器，保存模板配置 |

随后确认01～04条件并搜索。**模板不会改写已经算出的结果**；导入模板后如果武器变了，需要重新搜索。最终 Mod 导出使用所选结果中的武器。

模板中的武器强化、炼化和解锁状态会用于导出；百龙珠优先使用方案里的选择。防具与护石按计算结果生成，同一件防具可保留模板的强化数据，更换防具时强化数据会重置。Lua 的加载设置仍可能改变实际加载后的状态。

### 4. 导出并在游戏中加载

在结果卡片点击“Mod 导出”，填写配装名称和游戏装备组合栏位（1～224），保存文件。名称会显示在 Mod 列表和游戏组合中；所选栏位是**游戏的装备组合栏位，不是装备箱箱位**，原有组合会被替换。

两类方案放在不同目录。以下路径均相对于 `MonsterHunterRise/reframework/data/EquipmentLoadouts/`：

| 方案类型 | JSON 文件名 | 保存目录 |
| --- | --- | --- |
| 普通配装 | `栏位_时间戳.json` | `对应武器类型/`，如 `Bow/` |
| 仅使用已拥有的装备 | `owned_栏位_时间戳.json` | `OwnedPlans/对应武器类型/`，如 `OwnedPlans/Bow/` |

将文件放好后，到 Lua 的“配装列表”刷新，选择相应配装并加载，按提示确认。已有装备方案请保留 `owned_` 前缀，使用本地包附带的库存扩展脚本加载。加载后在游戏装备组合列表核对、调用该套组合；已有模式不会自动穿上配装。

### 加载前需要确认

- **普通方案可能创建装备**，并按“保留普通方案原装备”等设置处理目标组合原先关联的装备。请先检查 Lua“设置与工具”，不要直接覆盖需要保留的组合。
- **已有装备方案引用现有装备**，校验通过后只建立组合引用和插珠配置，不新建、强化或重新炼化装备，也不会凭空增加珠子。
- 普通导入中的武器词条解锁、防具强化设置会影响游戏里的最终状态；“满强化防御”只是工房显示的参考数值，不会自动把所有模式的装备强化到满级。
- 读取库存后若整理了装备箱、改动强化或炼化、百龙珠、猎虫配对，请重新导出库存再计算。提示不匹配时不要通过修改方案文件绕过检查。
- 网页的“导出 JSON”与“Mod 导出”用途不同；带入游戏要使用 **Mod 导出**生成的文件。

完整的模板保留范围、库存限制和故障核对方法见[游戏 Mod 与装备箱](docs/mod-integration.md)。

## 分享与恢复

| 想做什么 | 使用哪个功能 |
| --- | --- |
| 把搜索要求发给别人，让对方重新计算 | 复制条件／导入条件 |
| 保存或恢复一套完整配装 | 导出 JSON／导入方案 |
| 分享带完整装备、炼化和技能的图片 | 截图分享；接收者用“导入方案”读取图片或方案码 |
| 把方案带入游戏 | Mod 导入／Mod 导出 |

条件和 Mod 模板支持粘贴 JSON、拖入或选择文件。网页的普通方案 JSON 不能直接当作 Mod 文件加载。

分享图片建议发送原图。二维码可访问项目主页，方案数据也包含在其中；在工房“导入方案”里导入图片或粘贴扫码内容，即可恢复配装。已有装备方案也能分享给没有原库存的用户。

## 技能扩展分析（试用）

想知道满足目标后还能多出什么技能，可在结果区展开“技能扩展分析”，设置时限后点击“分析可新增技能”。

括号表示可以同时获得，例如“（刚心＋1，快吃＋1）”；不同组表示备选。通用资源组可展开选择具体技能，并点击“查看对应方案”。“仅选择技能”仅显示能获得所选任一技能增量的组合，不会将这些技能加入原目标。

候选尚未验证完成时，可继续补全，也可“停止并保留结果”。此功能仍在试用，列表不保证找齐所有可能性。有关通用资源和组数的详细解释见[技能扩展分析说明](docs/skill-extensions.md)。

## 炼化模拟

切换到“炼化模拟”，选择防具、炼化方式和次数，开始模拟。可指定保留与排序方式，也能按某个技能的等级排序。

命中统计可选择目标技能，或填写组合条件。例如，统计至少出现一个B级新增技能、且没有扣技能：

```text
grade.B >= 1 AND removed = 0
```

模拟只保留设定数量的结果供浏览，命中率仍按全部完成的样本统计。修改命中条件或保留方式后需要重新模拟。结果是抽样估计，不能预测游戏里下一次炼化；更多指令见[炼化模拟说明](docs/augment-simulator.md)。

## 装备清理

Lua 的“清理未引用”可删除未穿戴、且未被任何游戏装备组合引用的武器、防具和护石，支持按锁定、镶珠状态筛选。先扫描并勾选，核对后确认一次删除。

**建议非必要不使用此功能。删除前请在游戏外备份完整存档；需要保留珠子时，选择“未镶珠”范围或先拆珠。** 自动库存备份不能代替存档备份。保护范围及记录位置见[清理说明](docs/mod-integration.md#清理未引用装备)。

## 常见问题

- **换浏览器后数据不见了？** 条件、模板和库存保存在当前浏览器，不自动跨设备同步。重要内容请另存文件。
- **已有模式提示库存不匹配？** 重新从游戏导出装备箱，导入后重新选择武器实例并计算。
- **分享图片识别失败？** 使用原图，或改为发送方案码、方案 JSON。
- **导入模板后结果武器没有变？** 模板不会改写已算出的结果，请重新搜索；Mod 导出使用所选结果的武器。
