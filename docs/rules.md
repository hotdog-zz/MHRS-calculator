# 配装规则与数值口径

[返回文档目录](README.md)

## 规则范围

- 数据面向《曙光》最终内容版。武器普通孔按原生孔位计算；百龙珠、武器炼化和花链不参与目标技能求解。
- 普通模式下，每件防具最多七条内部炼化记录，cost 总和不超过该件预算。这里的记录不是装饰品孔。
- 原生技能种类＋新增技能种类不超过五种，删除技能不释放原生种类名额。
- 同件防具不能既增加又删除同一技能，删除不得超过原生等级。
- 自动搜索使用不浪费孔位的组合。手动填写和已有库存允许合计孔位增长溢出：每条按原始容量检查，最终孔位最多4-4-4，溢出部分仍计入记录和 cost；单件技能等级不能超出对应上限。
- 存在防御炼化记录时，防御增减合计不能为0；完全没有防御记录时允许。
- 检查炼化最终状态，不验证随机生成顺序或种子可达性。已有模式直接使用库存中的实际炼化和护石，不按普通搜索规则重新生成。
- 风雷合一的额外加成在 Mod 全导入时计入目标，求解按基础技能搜索，因此可能保守。
- 基础防御显示和排序不包含铠玉强化、武器炼化等效果，不等于游戏最终面板防御；工房不计算伤害。

### 防御兜底

“执行防御兜底”默认关闭。开启后，保留六条自由记录且仍有预算时，追加第七条防御收尾；预算已经耗尽时直接结束。七条结果必须保留防御记录。未炼化装备可以直接使用；不足六条且仍有预算的结果，需要存在可失败的普通抽选，才能按连续失败结束处理。

收尾从所属池中选择预算内 cost 最大的条目，相同 cost 沿用源表先后。该条目的所有有效防御取值均可使用；防御优先时选择满足其他约束的较高取值。收尾最多一条，不反复消耗剩余预算。专用收尾不能作为短结果中的普通自由词条。

自动生成的六条构型若在收尾时防御恰好相消，会先尝试重选已有防御词条的合法数值，并继续考虑收尾条目的其他合法取值，保留最终防御最高的合法组合。条目ID、cost及记录数不变，技能和孔位不变；重复防御记录可分别选择数值。全部取值仍无法修复时，才排除该构型并继续搜索。固定炼化及库存装备不会被这一过程改写。

收尾占用炼化记录并参与预算、防御及合法性检查，不计入新增正面词条上限。普通耐性按类别与属性分组，不能保留合计为0的抵消记录。手填炼化也执行相应检查；已有库存按实际装备记录读取，不重新生成炼化。

词条展示、分享图片和 Mod 导出按内部类别、带符号 cost、实际效果值依次升序排列，三项相同保留原有先后，不额外按技能或属性 ID 排序。新生成方案先展开单条记录，并安排新增技能的引入顺序；库存原有同键记录保留先后。收尾可能排在防御记录中间，预算摘要与实际收尾标记保持对应。关闭收尾时使用七条自由组合的宽松规则，不代表完整的游戏生成过程；工房不验证随机种子。

## 求解与结果统计

自动搜索得到方案后，会按五件防具的原始耐性与炼化变化之和，统一分配自动生成的正、负耐性词条：优先提高整套最低耐性，相同时再提高第二低值，依此类推。每条仍属于原防具，数值、cost和记录数保持不变。固定炼化和库存装备只参与总值计算，其词条不变；分配结果随截图和Mod方案一起保存。此处不计耐性技能、猫饭等额外加成。

开启“执行防御兜底”时，数量模式以及非防御指标的时限模式使用最多六条自由词条建模，出解后按实际剩余预算选择第七条防御收尾。按时限优化“基础防御从高到低”时，则将防御收尾的预算档位与实际收益完整计入模型。若不足六条且仍有预算，会先尝试补充普通正防御词条，优先形成预算耗尽或合法七条结束的结果；只有无法合法补充时才保留可连续失败结束的短结果。此规则同时适用于数量和时限模式。固定炼化与已有装备保持原样。关闭兜底时仍允许最多七条自由词条，数量模式会尝试用普通正防御补充剩余预算。

结果中的“空余孔位”是武器、五件防具和护石上未插珠子的普通孔位等级之和，不含百龙孔。例如空着一个4级孔、两个1级孔，显示6；4级孔即使只插入1级珠，也视为整个孔已占用，贡献0。可展开“查看逐孔插法与空余孔位”查看详情。

结果和分享图片同时显示基础防御、满强化防御及火、水、雷、冰、龙五种基础耐性。基础防御含角色自带的1点防御、武器原生防御加成和防具炼化变化，不含铠玉强化；满强化防御假设五件防具均达到最终版本各自的强化上限，并保留角色自带的1点防御、武器原生防御加成及炼化变化。基础耐性是五件防具含炼化后的总和，并计入同系列防具加成：同系列3件、4件、5件分别使五种耐性各增加1、2、3点。系列按游戏数据中的系列ID判断，结果与分享图片会注明已计入的加成。两种防御和耐性均不计技能、道具、猫饭及花链等额外加成；满强化数值仅供查看，不会改变装备箱的实际强化或Mod导出中的强化数据。

选择“空余孔位等级总和从大到小”时，结果按所有未使用普通孔的等级之和降序排列，相同则优先基础防御；按时限搜索也直接优化这一总和。已插珠子的孔按整孔占用计算，例如1级珠插入4级孔会占用整个4级孔，不会留下3点空余。

数量模式优先找到指定数量的可行方案，结果按所选指标排序；它不承诺排序指标全局最优。时限模式按基础防御优化时包含防御兜底收益，其他指标优先优化各自目标，收尾后的实际防御用于结果比较。所有展示均使用补充及收尾后的最终数值。不合法的后置收尾会排除对应自由词条构型后继续搜索，不排除整组防具。

基础防御越高越优时选择降序，新增技能 cost 越低越优时选择升序。新增技能 cost 只合计防具炼化增加技能的费用，不包含孔位、其他属性或删除技能返还的费用。

搜索使用两个独立计算 Worker，可能占用较多 CPU 和内存；停止搜索会结束两路计算。未找到方案不代表一定无解，可以延长时限或放宽条件。结果不保证全局最优。
