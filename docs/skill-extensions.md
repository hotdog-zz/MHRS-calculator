# 技能扩展分析

[返回文档目录](README.md)

此功能仍标记为“试用”。它寻找在原目标和当前固定条件、炼化上限下，可以同时增加的技能组合；没有发现不等于已经证明不存在。

## 分析与验证方式


在配装结果区展开“技能扩展分析”，选择“全部可提升技能（骨架内）”，或选择具体关注技能，然后点击“分析可新增技能”。它先用原目标分别优化空余孔位、正面词条占用，每个搜索 Worker 最多保留20套骨架，按孔位、预算、自由记录和03名额等不同方向保留资源分布；先在固定防具、护石下补充空孔个数优化，区分一个二级孔和两个一级孔；再在固定防具的小模型内分析技能，并可在全技能范围内放开未指定的护石联动。取消12项关注限制，全技能不会进入最初的全装备大模型。分析会在开始时01～04条件的快照下重新搜索，保留固定装备、炼化、护石和03逐件新增正面词条上限；已有模式继续使用库存实例和珠子数量。

括号内的技能增量表示可以同时获得，例如“（刚心 +1，快吃 +1）”。增量相对原目标计算，未要求的技能从0级开始；实际有效等级按游戏上限截断。包含关系按两类资源分别判断：孔位等级、炼化技能 cost 各自从高到低排列，较强组的每个位置都不低于对应位置才可包含。例如（2级孔位，1级孔位）可包含两个1级孔位，但单个2级孔位不能包含两个1级孔位；B级及以下的位置可包含C级及以下的位置。组内指定技能也须逐项达到相同或更高等级。被包含的组只合并标题，合法方案和候选来源继续保留；不会拆分孔位或把多个位置的费用相加抵扣。

通用模板支持3、6、9、12、15 cost上限的技能位置，以及实际1至4级孔位；高级孔可选择多级珠、多技能珠。费用与孔等级表示上限，多个位置共享逐件预算，不承诺任意候选可以自由组合。资源位置可以留空。“仅选择技能”不改变分析范围：先分析全部可提升技能，再仅显示能实际获得所选任一技能增量的组合。它不会把所选技能加入原配装的必选条件。通用模板会验证实际替换能力，即使搜索样本中没有该技能，也能在替换合法时匹配；无法获得所选技能增量的组合不显示。待验证模板会单独计数，尚未完成不代表不可行，可点击“继续检查待验证模板”。单个位置会自动枚举并校验全部候选，列表标记“该模板候选已验证完毕”后才表示该模板已遍历完成；没有通过校验的技能不会列入。固定炼化及库存装备的炼化不能被替换。同一技能增量的炼化、珠子等不同实现方式会分别保留；替换后会重新选择对应cost词条、重算防御与兜底，必要时可以扣除未要求的原生技能，或调整合法负防御、负耐性词条来回收预算，固定炼化和库存防具不参与这种调整。多个位置点击“补全并验证替换选项”，每次最多显示100个联合校验通过的组合，可继续验证下一批。候选补全在独立Worker中分批执行，可停止并保留已验证结果。列表保存替换选择，查看方案时再生成完整装备数据，避免一次保存所有完整方案。“1级孔位 ×2”需要同一方案能同时插入两颗一孔珠；一个空2级孔仍只有一个位置，不能拆成两个1级孔。选择框列出有效组合及对应方案，不承诺候选技能任意交叉搭配。每个骨架记录各等级空孔、逐件剩余预算、自由记录和03名额；自动补上的正防御与防御收尾先从核心构型移除，扩展完成后重新收尾，固定炼化与库存不变。点击“查看对应方案”后可使用原有的截图、方案JSON和Mod导出。

分析时限可选90、180、270或360秒，默认90秒，资源扩展组上限可选60、90、180或270组，同一模板的具体替换选项不额外占用组数。插珠验证优先完成整组组合，避免单颗珠子的中间结果先占满上限。停止或达到上限后保留已发现结果；资源骨架是有限采样，局部求解完成也不代表全局扩展组已经穷尽。超时未发现扩展不代表一定没有可扩展技能。此处不验证游戏随机种子。

## 组数的三个口径

- 搜索样本是保留下来的具体装备方案，一个样本可能有多种资源解释。
- 页面先展开资源解释，合并相同模板和被包含模板，再进行所选技能筛选；显示的组数只包含已有合法匹配方案的组。没有确认的模板单独计为待验证。
- 搜索停止上限目前按每个样本的首个资源模板去重计数，发生在显示合并与筛选之前。因此达到60组上限，不保证最终显示60组；部分较弱模板仍可能占用搜索名额。这是当前实现的限制。

同一资源模板内的具体技能选择不额外占组数。两路搜索各自最多保留20套骨架，不等于最终只能显示20组或40组。
