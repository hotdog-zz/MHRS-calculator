# 炼化模拟与命中统计

[返回文档目录](README.md)

切换到“炼化模拟”页，选择一件防具和普通炼化、技能特化、插槽特化或稳定型，再填写模拟次数。Pool13防具不提供技能、插槽特化。模拟每次都从原生装备开始，不在上一轮的结果上叠加。

- 次数可设为1～1000万；一次指完整炼化，包含其内部重抽、失败和相消。运行中可以停止，已完成样本会保留。
- 先选择保留指标和容量，最多保留5000组。相同词条内容合并计数，未保留的明细直接丢弃，但所有完成的抽选仍计入总次数、平均值、极值和目标命中统计。不保存全部JSON，抽选次数增加不会无限累积列表。
- 结果每页显示25组，可以随时按防御、孔位增长、新增技能等级、新增技能cost、出现次数，或某个指定技能的等级重排已保留结果。指定技能支持升降序，以及“最终单件等级（含原生）”“炼化新增等级”两种口径；也可以在开始前用同样的指标挑选需要保留的结果。更改全量结果的保留指标需要重新模拟；已丢弃的结果无法通过重排恢复。
- 可搜索一个技能，统计单件最终达到指定等级的次数，包含原生等级。命中率来自全部样本，是抽样估计，不是精确理论概率。也可以在“命中条件指令”填写组合条件；有设置单个目标技能时，需要同时满足两者。改变指令后需重新模拟，已丢弃的明细不能用于重新统计。
- 留空种子会自动生成；相同防具、模式和种子可重复得到相同的抽选过程。这个种子不对应游戏存档，不能预测自己接下来的炼化结果。
- 模拟按模式固定步骤、抽选权重、预算检查、技能容量、抵消、费用回滚、防御收尾和连续失败结束运行。不会使用配装工房的耐性均衡或主动取最大防御值。结果中的防御和耐性是该件防具含炼化的数值，不含铠玉强化、角色基础防御、同系列加成及技能等额外效果。

扩孔词条在接受阶段不因空间不足而拒绝，也不会逐条改小。全部生成结束后，才把增长点数之和应用到原孔位，最终最多4-4-4。例如4-4-2抽到＋3和＋1，两条记录及原cost均保留，总增长4点，实际应用2点；溢出不返还费用，也不停止后续抽选。

结果同时显示词条扩孔、实际扩孔和溢出点数。现有“词条扩孔点数”排序与 `slots` 指令仍按未截断点数；新增 `effective_slots` 统计实际增长，`overflow_slots` 统计溢出。例如 `effective_slots = 2 AND overflow_slots > 0` 会包含原始总增长大于2、最终实际增长为2的结果。

命中指令支持比较运算、`AND`、`OR`、`NOT`及括号，例如：

```text
grade.B >= 1 AND removed = 0
grade_at_least.B >= 1 AND NOT (removed > 0)
added("攻击") >= 1 AND skill("看破") >= 2
```

`grade.B`按最终保留的B档新增技能等级计数；`grade_at_least.B`包含B档及以上。D/C/B/A/S分别对应炼化cost 3/6/9/12/15，原生技能不计入新增档位。`removed = 0`表示最终没有扣技能记录，已相消或重启时撤销的词条不计入；防御、耐性扣除不属于扣技能。`skill("技能名称或ID")`为最终等级，`added("技能名称或ID")`、`removed("技能名称或ID")`为对应的新增、扣除等级。页面的“字段与示例”列有其他可用字段。

模拟在独立Worker中执行，不调用配装求解器。配装搜索与炼化模拟需要先停止其中一个，再运行另一个。停止后仍可浏览结果；“清空结果并释放内存”会关闭模拟Worker并释放保留列表。当前实现已做规则案例与统计测试，尚需游戏内逐次结果对照验证。
